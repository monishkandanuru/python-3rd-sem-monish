# Python 3rd Semester Programs

This repository contains beginner-friendly Python programs collected and organized for VS Code practice.

## Programs

| Program | Description | Sample output |
| --- | --- | --- |
| `factorial_using_loops.py` | Finds the factorial of a number using a loop | `output_factorial.txt` |
| `fibonacci.py` | Prints Fibonacci numbers using recursion | `output_fibonacci.txt` |
| `nested_loop.py` | Prints a right-triangle star pattern | `output_nested_loop.txt` |
| `pnotp.py` | Checks whether a number is prime | `output_prime_check.txt` |
| `program 1.py` | Calculates student total and average marks | `output_student_details.txt` |
| `program 2.py` | Demonstrates arithmetic operators | `output_arithmetic_operations.txt` |
| `random_function.py` | Generates a random even number from 0 to 98 | `output_random_function.txt` |
| `random_otp_gen.py` | Generates a random OTP with the requested number of digits | `output_random_otp.txt` |

## Run in VS Code

1. Install Python 3.
2. Open this repository folder in VS Code.
3. Open any `.py` file.
4. Select **Run Python File** or run `python filename.py` in the integrated terminal.
5. Enter the requested values when prompted.

The output files are sample terminal sessions captured for example inputs. Random programs produce different values each time.
